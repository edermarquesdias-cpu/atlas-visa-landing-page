# Screenshot Assets

Upload the final Atlas Visa screenshots to this folder using these exact filenames:

- `hero-desktop.webp` — full hero and primary conversion actions
- `services.webp` — services / value presentation
- `process.webp` — process or step-by-step section
- `faq-contact.webp` — FAQ plus lead-generation / contact flow
- `mobile.webp` — representative mobile experience

## Presentation Rules

- Use only final production/demo visuals.
- Keep the fictional portfolio disclaimer intact in the repository.
- Prefer clean browser captures without unrelated tabs or personal data.
- Show both visual hierarchy and conversion flow, not only decorative sections.
- Mobile evidence should demonstrate real responsive layout and usable CTAs.
